PREMIUM SERVICES

A forward-looking policy: the commitments that would apply if the platform ever introduces paid features. There are none today.

Last updated 2026-08-01 Version v1.0

◈
Scope: This document applies only to app.keydir.in and its related services.

SECTION_01 Current Status

ℹ
There are no paid features today. The KeyDir Application and its directory data are free to use. This policy exists so that, if paid features are ever introduced, the terms are already defined and the community's core expectations are protected.

SECTION_02 What Premium Would Cover

If premium services launch, they would cover optional conveniences — such as additional account features or tools for vendors and builders — never the core directory data, which remains free.

SECTION_03 What Premium Would Never Buy

✗An organic ranking, placement, or removal of another listing.
✗Removal of negative reviews, flags, or warnings.
✗Access to other users' data, or control over another account.
✗Influence over review or vote integrity.

SECTION_04 Free Access Stays Free

The directory and its core features remain free to everyone. Premium features would be additional, optional, and clearly identified. No existing free functionality will be moved behind a paywall.

SECTION_05 If Premium Launches

Before any paid feature launches, these terms will be finalized, pricing and scope will be published, and this policy will be updated. Nothing in this section is a commitment to launch premium services at all.
