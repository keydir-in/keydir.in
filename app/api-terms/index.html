Scope: This document applies only to app.keydir.in and its related services.

A public API is planned but not yet available. This page describes the intended terms. Developer access is not currently open, and no current service is bound by these terms.

SECTION_01 Status

The KeyDir Application intends to offer developer access to directory data. Until the API launches, these terms are a preview. If you want to build on the data in the meantime, contact us first rather than scraping.

SECTION_02 What the API Will Provide

  • Read access to directory data — vendors, builders, brands, and products.
  • Documented, rate-limited endpoints with keys.
  • Response data consistent with the information shown in the app.

SECTION_03 Planned Access Rules

  • Use a registered API key; identify your application.
  • Respect rate limits and caching requirements.
  • Attribute the platform as the data source when displaying its data.
  • Keep keys confidential.

SECTION_04 Restrictions

✗Reselling the data or repackaging it as a competing directory.
✗Circumventing rate limits or access controls.
✗Using the data in a way that misleads users about its source or accuracy.
✗Collecting user data or personal information beyond what the API exposes.

The Acceptable Use Policy and Licenses continue to apply.

SECTION_05 Changes to These Terms

These terms are a draft and will be finalized before the API opens. Final terms will be posted here and on the Contact page.
